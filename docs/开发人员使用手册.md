# hashkit 脚本使用手册(开发人员)

## 1. 作用

为交付文件生成 MD5 哈希清单,并按清单校验文件是否被改动。共 4 个脚本,Linux 与 Windows 各一套:

| 脚本 | 系统 | 作用 |
|------|------|------|
| `gen-md5.sh` | Linux | 为脚本所在目录及全部子目录中的文件生成 MD5 清单,保存为同目录的 `MD5.txt` |
| `gen-md5.bat` | Windows | 同上 |
| `verify-md5.sh` | Linux | 按脚本所在目录的 `MD5.txt`,校验该目录及全部子目录中的文件 |
| `verify-md5.bat` | Windows | 同上 |

## 2. 使用前准备

将下列文件与交付文件放在**同一个目录**(交付文件可以放在子目录中),按所用系统选取:

- Linux:`hashkit-linux-amd64`、`gen-md5.sh`、`verify-md5.sh`
- Windows:`hashkit.exe`、`gen-md5.bat`、`verify-md5.bat`

Linux 下首次使用需赋予执行权限:

```bash
chmod +x hashkit-linux-amd64 gen-md5.sh verify-md5.sh
```

脚本以**自身所在目录**为操作目录,在任何位置执行结果都相同;Windows 下也可直接双击运行。

## 3. 生成清单:gen-md5

```bash
# Linux
./gen-md5.sh

# Windows:双击 gen-md5.bat,或在命令行执行
gen-md5.bat
```

执行成功后,屏幕提示已写入的文件数,目录下生成 `MD5.txt`:

```text
已写入 5 项 -> ./MD5.txt
```

`MD5.txt` 每行为"MD5 值、两个空格、相对路径":

```text
60b725f10c9c85c70d97880dfe8191b3  a.txt
3b5d5c3712955042212316173ccf37be  sub/b.txt
```

清单**不包含**以下工具文件:`hashkit` 可执行文件(`hashkit-linux-amd64`、`hashkit.exe`)、`gen-md5` 和 `verify-md5` 脚本(`.sh`、`.bat`)、`MD5.txt` 自身。仅排除脚本所在目录第一层的这些文件,子目录中的同名文件仍会计入。

交付时请将 `MD5.txt` 随交付文件一并提供。重复执行会覆盖旧清单。

## 4. 校验文件:verify-md5

```bash
# Linux
./verify-md5.sh

# Windows:双击 verify-md5.bat,或在命令行执行
verify-md5.bat
```

校验结果逐文件显示,最后一行为合计:

```text
a.txt: 通过 ✔ [MD5]
sub/b.txt: 不一致 ✘
  期望: 3b5d5c3712955042212316173ccf37be
  实际 [MD5]: 6010c8d187687e6c6879343f0841212d

合计 2 项:通过 1,不一致 1,无法读取 0
```

| 输出 | 含义 |
|------|------|
| `通过 ✔` | 文件与清单一致 |
| `不一致 ✘` | 文件内容与清单不一致,须重新获取该文件或重新生成清单 |
| `无法读取` | 清单中的文件不存在或无权限读取(文件名须与清单完全一致,含大小写) |

## 5. 退出码

两类脚本的退出码相同,便于在其他脚本中判断:

| 退出码 | 含义 |
|--------|------|
| 0 | 生成成功 / 全部一致 |
| 1 | 存在不一致或无法读取(仅校验脚本) |
| 2 | 运行出错,如缺少 `hashkit` 可执行文件,或校验时缺少 `MD5.txt` |

## 6. 注意事项

1. 清单不含工具文件(见第 3 节),因此工具文件被替换或修改不影响校验结果,也不会被校验。
2. 清单只校验其中列出的文件,不会发现目录里多出来的文件。
3. 文本类文件(`.sql`、`.sh`、`.properties` 等)经 Git 或 Windows 转换换行符后,哈希值会变化,校验失败时请先排查此项。
4. 清单与文件一起被替换时校验仍会通过。涉及生产的文件,建议通过另一个渠道(如工单系统)再核对一次清单。
